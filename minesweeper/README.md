# Minesweeper AI

This project was completed as part of Harvard University's CS50's Introduction to Artificial Intelligence with Python.

## Overview
This project implements an AI agent capable of playing Minesweeper using logical inference and knowledge-based reasoning.

The AI analyzes the game board, infers safe moves, and identifies mines based on available information.

## Concepts Used
- Knowledge Representation
- Logical Inference
- Artificial Intelligence
- Game Solving

## Technologies
- Python

## Files
- `minesweeper.py` — Minesweeper game and AI logic
- `runner.py` — Runs the game interface
