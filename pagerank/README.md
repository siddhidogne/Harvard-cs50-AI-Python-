# PageRank Algorithm

This project was completed as part of Harvard University's CS50's Introduction to Artificial Intelligence with Python.

## Overview
This project implements the PageRank algorithm used to rank web pages based on link structures between pages.

The project explores probability distributions, iterative algorithms, and web search ranking concepts.

## Concepts Used
- PageRank Algorithm
- Probability
- Markov Chains
- Iterative Computation

## Technologies
- Python
- NumPy

## Files
- `pagerank.py` — Main implementation of the PageRank algorithm
