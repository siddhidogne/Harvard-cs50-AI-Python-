# Tic Tac Toe AI

This project was completed as part of Harvard University's CS50's Introduction to Artificial Intelligence with Python.

## Overview
This project implements an AI agent that plays Tic Tac Toe optimally using the Minimax algorithm.

The AI evaluates all possible future game states to determine the best possible move.

## Concepts Used
- Minimax Algorithm
- Game Theory
- Search Algorithms
- Artificial Intelligence

## Technologies
- Python

## Files
- `tictactoe.py` — AI and game logic
- `runner.py` — Runs the game interface
