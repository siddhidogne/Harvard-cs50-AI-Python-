# Shopping Prediction

This project was completed as part of Harvard University's CS50's Introduction to Artificial Intelligence with Python.

## Overview
The objective of this project is to build a machine learning model that predicts whether a user will complete an online shopping purchase based on browsing behavior data.

The project involves data processing, training a classification model, and evaluating prediction accuracy.

## Concepts Used
- Machine Learning
- Classification Algorithms
- Data Processing
- Model Evaluation

## Technologies
- Python
- scikit-learn
- NumPy
- CSV Data Handling

## Files
- `shopping.py` — Main machine learning implementation
- `shopping.csv` — Dataset used for training/testing
