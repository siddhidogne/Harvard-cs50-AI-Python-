# Crossword Generator

This project was completed as part of Harvard University's CS50's Introduction to Artificial Intelligence with Python.

## Overview
This project implements an AI-based crossword puzzle generator using constraint satisfaction algorithms.

The system fills crossword grids by enforcing constraints and applying logical inference techniques to determine valid word placements.

## Concepts Used
- Constraint Satisfaction Problems (CSP)
- Backtracking Search
- Artificial Intelligence
- Logical Inference

## Technologies
- Python

## Files
- `generate.py` — Main crossword generation algorithm
- `crossword.py` — Crossword structure and constraint handling
