# Knights and Knaves Logic Puzzle

This project was completed as part of Harvard University's CS50's Introduction to Artificial Intelligence with Python.

## Overview
This project solves logical reasoning puzzles involving knights and knaves using propositional logic.

Knights always tell the truth, while knaves always lie. The AI determines the correct identities based on logical statements.

## Concepts Used
- Propositional Logic
- Knowledge Representation
- Logical Inference
- Artificial Intelligence

## Technologies

- `logic.py` — Logical reasoning engine
