# Attention Mechanism Visualization

This project was completed as part of Harvard University's CS50's Introduction to Artificial Intelligence with Python.

## Overview
This project explores attention mechanisms used in natural language processing and modern deep learning models.

The system visualizes how attention focuses on different parts of input text while processing language data.

## Concepts Used
- Natural Language Processing (NLP)
- Attention Mechanisms
- Deep Learning
- Neural Networks

## Technologies
- Python
- TensorFlow
- NumPy
