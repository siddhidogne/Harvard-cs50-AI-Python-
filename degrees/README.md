# Degrees of Separation

This project was completed as part of Harvard University's CS50's Introduction to Artificial Intelligence with Python.

## Overview
This project finds the shortest connection path between actors based on shared movie appearances.

The system models relationships as a graph and applies search algorithms to determine degrees of separation.

## Concepts Used
- Breadth-First Search (BFS)
- Graph Theory
- Search Algorithms
- Artificial Intelligence

## Technologies
- Python

## Files
- `degrees.py` — Main search algorithm implementation
- `util.py` — Utility functions and data structures
