# Heredity Probability Model

This project was completed as part of Harvard University's CS50's Introduction to Artificial Intelligence with Python.

## Overview
This project uses probability theory to predict the likelihood of individuals inheriting specific genetic traits.

The system applies Bayesian inference and probabilistic reasoning to analyze hereditary data.

- Probability
- Bayesian Inference
- Artificial Intelligence
- Genetic Trait Prediction
