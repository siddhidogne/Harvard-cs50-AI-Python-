# Sentence Parser

This project was completed as part of Harvard University's CS50's Introduction to Artificial Intelligence with Python.

## Overview
This project implements a natural language parser capable of analyzing sentence structures using context-free grammar rules.

The system identifies noun phrases and parses sentences into grammatical structures.

## Concepts Used
- Natural Language Processing (NLP)
- Context-Free Grammar
- Sentence Parsing
- Artificial Intelligence

## Technologies
- Python
- NLTK

- `parser.py` — Main parsing implementation
- `requirements.txt` — Project dependencies
