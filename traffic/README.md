# Traffic Sign Recognition

This project was completed as part of Harvard University's CS50's Introduction to Artificial Intelligence with Python.

## Overview
The goal of this project is to build a neural network capable of classifying traffic signs from images.

The model is trained using image data and deep learning techniques to recognize different categories of traffic signs.

## Concepts Used
- Computer Vision
- Deep Learning
- Neural Networks
- Image Classification

## Technologies
- Python
- TensorFlow
- OpenCV
- NumPy

## Files
- `traffic.py` — Main training and testing script
- `requirements.txt` — Required dependencies
