# Nim Game AI

This project was completed as part of Harvard University's CS50's Introduction to Artificial Intelligence with Python.

## Overview
This project implements an AI capable of learning and playing the game of Nim using reinforcement learning techniques.

The AI improves its gameplay strategy over time through self-play and experience.

## Concepts Used
- Reinforcement Learning
- Game AI
- Q-Learning
- Artificial Intelligence

## Technologies
- Python

## Files
- `nim.py` — Game logic and AI implementation
- `play.py` — Interface to play against the AI
